Игровой мир представляет собой поле размером N×N клеток, на котором случайным образом размещаются ямы, Вампус и золото. Количество ям должно увеличиваться пропорционально числу клеток поля. Стартовая клетка охотника и соседние с ней клетки должны обеспечивать безопасное начало игры.
Цель охотника — найти золото и вернуться в стартовую клетку, избежав гибели. Убийство Вампуса не является обязательным условием победы. Охотник имеет одну стрелу, которую может выпустить по прямой в направлении своего взгляда.
Охотник изначально не знает расположения объектов и получает информацию об окружении с помощью датчиков:
Запах — рядом находится живой Вампус.
Ветерок — рядом находится хотя бы одна яма.
Блеск — золото находится в текущей или соседней клетке.
Удар — охотник попытался выйти за границы поля.
Крик — Вампус был убит стрелой.
